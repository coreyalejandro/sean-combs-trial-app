# The Combs Trial

A day-by-day visual story of the 2025 federal trial *United States v. Sean Combs* (S.D.N.Y., No. 24-cr-542): one picture for each of the 28 days the jury heard testimony (May 12 to June 24, 2025), then the verdict and sentence, then a finale that pulls back from one courtroom to about 78 million survivors walking to Washington.

Live site: https://sean-combs-trial-app.pages.dev (Cloudflare Pages, deployed from the `main` branch).

**Status of this branch (`v2-29-visualizations`):** the scaffold. Every route builds and shows its question, sources and a sourced table of the day's figures; the 28 pictures and the finale are being built in `src/viz/day-NN/` and `src/app/finale/`. See `CONTRIBUTING-VIZ.md`.

## How it is built

- Next.js 14 (App Router), `output: 'export'` and `trailingSlash: true`: `npm run build` writes a fully static site to `out/`. No server, no database, no API.
- All facts come from one file, `src/data/trial_days.json` (28 testimony days and the verdict, each fact with its outlets, sources and confidence). Two scaffold tables sit beside it: `src/data/shared/witnesses.json` (the 34 witnesses, generated by `npm run build:witnesses`) and `src/data/shared/charges.json` (the five counts).
- `src/lib/data` reads the data (typed loader, source resolution, confidence, third-party redaction). `src/components/shell` is the page shell. `src/viz/day-NN/` holds each day's picture.

## Run it

```bash
npm ci
npm run dev                 # http://localhost:3000
npm run build               # writes out/
npm start                   # serves out/
```

## Test it

```bash
npm run typecheck
npm test                    # no-hand-typed-numbers scan + unit tests (data, registry, additions)
npm run lint
npm run build && npm run test:e2e   # every page at 1280 px and 390 px, sources, axe, no-JS, keyboard
```

## Cloudflare Pages settings

- Build command: `npm ci --legacy-peer-deps && npm run build`
- Build output directory: `out`
- Environment variable: `NODE_VERSION=22`

No secrets or environment variables are needed.

## Care

Every number links to the outlet that reported it. No survivor is tracked or named; pseudonymous witnesses appear only by pseudonym; third parties are not named; testimony is summarised without graphic detail. Every page links to support (RAINN 800.656.HOPE, 988, the National Domestic Violence Hotline).
